# DalaChain — оқу блокчейні

Блокчейннің жұмыс принципін көрсететін веб-жоба: блоктар, SHA-256 хеш, Proof-of-Work майнинг,
secp256k1 кілттері бар әмияндар, цифрлық қолтаңбалы транзакциялар, тізбекті тексеру және
блокты бұрмалау демонстрациясы.

## Технологиялар
- Node.js 18+ және Express
- Node.js crypto модулі (SHA-256, ECDSA secp256k1)
- HTML, CSS, JavaScript (фронтенд)

## Жергілікті іске қосу
    npm install
    node server.js
Браузерде: http://localhost:3000

## Render-ге орналастыру
- Build Command: npm install
- Start Command: node server.js
